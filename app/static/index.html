Alert Rules

A rule's instrument, direction and threshold cannot be changed after creation. To change them, disable the rule and create a new one.

Alert History

Rows come from the alert_events table, recorded by PostgreSQL when a tick crossed a rule's threshold. Newest first, last 50.

Instruments

Demo / Manual Tick

Sends one price tick to POST /ticks/ingest. The server calls the PostgreSQL function ingest_tick() with source MANUAL. That function stores the tick, rejects duplicates, and fires alert rules. The browser only sends the tick.

Offline replay

The replay feed runs from the terminal, not from the browser:

python -m app.replay data/replay_prices.csv --delay-ms 300

Press Refresh here to see the ticks and alerts it creates.
