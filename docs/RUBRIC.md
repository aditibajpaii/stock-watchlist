# BCSE302P Project Rubric

Course: BCSE302P – Database Systems Lab
Faculty: Dr. Anand Bihari

Project: Real-Time Stock Market Watchlist & Alert System

## Official marks

| Component | Marks |
|---|---|
| ER Diagram | 3 |
| Table creation with description and screenshots | 5 |
| Normal forms | 2 |
| **Total** | **10** |

## Required report sections (fixed order)

- Abstract
- Table of Contents
1. Introduction
2. Project Scope
3. Key Contacts and Stakeholders
4. Project Resource Requirements
5. ER Diagram
6. Tables and Constraints
7. Work Breakdown
8. Review Evaluation

## Required for EVERY table

- table description
- relationships
- normal form satisfied
- screenshot of the CREATE TABLE statement

## Team arrangement

- Technical implementation: one student.
- Other team members write the report themselves from factual notes
  (docs/FACT_SHEET.md) and evidence (docs/EVIDENCE_CHECKLIST.md).

## Priority

Database quality (schema, relationships, constraints, normalization,
evidence) has priority over frontend complexity.
